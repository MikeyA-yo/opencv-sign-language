HandSigns
Signs Embed API

A small interpreter for yes, no, and okay.

Hold a thumbs up, thumbs down, or OK circle in the camera. The widget reads 21 hand landmarks in the browser and names the sign. Nothing is uploaded.

Live camera

The first visit downloads an ~8 MB hand model (progress shows under Start camera). After that, the camera opens right away. Use a plain background and keep the hand large in the frame.

Supported signs

YES

Thumbs up Fold four fingers. Point the thumb straight up.

NO

Thumbs down Fold four fingers. Point the thumb straight down.

OKAY

OK circle Touch thumb tip to index tip. Keep the other three fingers up.

HELLO

Open palm All fingers extended, palm toward the camera.

PEACE

V sign Index and middle up; ring and pinky folded.

POINT

Index up Only the index finger extended.

FIST

Closed hand All fingers folded.

ILY

I love you Thumb, index, and pinky extended (ASL).

Plug into a website

Drop in one script and one custom element. Recognition runs on the visitor’s machine.

<script type="module" src="/static/handsigns-widget.js"></script>
<hand-signs speak></hand-signs>

<script type="module">
  const el = document.querySelector("hand-signs");
  el.addEventListener("signchange", (event) => {
    console.log(event.detail.sign, event.detail.confidence);
  });
</script>

Python / OpenCV API

The same classifier is available as a REST endpoint for still images (OpenCV decode + MediaPipe landmarks). 

curl -F "file=@hand.jpg" http://127.0.0.1:8000/api/recognize

See README.md for the webcam demo, JSON schema, and how to call this from your own backend.

HandSigns is a starter module, not a full sign-language translator. It covers a handful of held poses used for basic yes / no / okay communication.
